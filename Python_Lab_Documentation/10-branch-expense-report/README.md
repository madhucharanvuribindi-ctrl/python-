# Branch Expense Report

## 1. Aim
Calculate branch and category expenses, monthly averages and the highest-expense branch.

## 2. Algorithm
1. Start.
2. Store branches, categories and monthly expenses.
3. Initialize branch and category totals.
4. For each branch, calculate each category's three-month total.
5. Add category totals to branch total and category totals.
6. Track largest category total within each branch.
7. Calculate branch monthly average.
8. Find branch with highest expenses.
9. Display totals and highest category.
10. Stop.

## 3. Sample input
Uses the expense records stored in the Python program.

## 4. Sample output
```text
Branch Expense Report
North total: 14000
Monthly average: 4666.67
South total: 13650
Monthly average: 4550.0
East total: 15000
Monthly average: 5000.0

Largest category in one branch: Salary in East
```

## 5. Conclusion
This program demonstrates multidimensional lists, nested loops, aggregation and comparison.
