# Repeated Word Finder

## 1. Aim
Find words that occur more than once in a sentence and show their first positions.

## 2. Algorithm
1. Start.
2. Read a sentence.
3. Convert sentence to lowercase.
4. Split sentence into words.
5. Visit each word.
6. Count occurrences of that word.
7. If count is greater than one, find its first position.
8. Display repeated word and first position.
9. Stop.

## 3. Sample input
Sentence: Apple mango apple

## 4. Sample output
```text
Repeated Word Finder
Enter a sentence: Apple mango apple
apple is repeated. First position: 1
apple is repeated. First position: 1
```

## 5. Conclusion
This program demonstrates strings, lists, lowercase conversion, splitting and searching.
