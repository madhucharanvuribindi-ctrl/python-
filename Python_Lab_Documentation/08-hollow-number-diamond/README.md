# Hollow Number Diamond

## 1. Aim
Print a hollow diamond number pattern for a selected number of rows.

## 2. Algorithm
1. Start.
2. Read number of rows as an integer.
3. If input is invalid, display an error message.
4. If rows is less than 1, display a validation message.
5. Print the upper half using spaces and edge numbers.
6. Print the lower half in reverse order.
7. Stop.

## 3. Sample input
Number of rows: 4

## 4. Sample output
```text
Hollow Number Diamond
Enter the number of rows: 4
   1
  2 2
 3   3
4     4
 3   3
  2 2
   1
```

## 5. Conclusion
This program demonstrates nested loops, pattern printing and exception handling.
