# Student Marks Calculator

**Original program file:** `task.py55`

## 1. Aim
Calculate a student's total and average marks and determine pass or fail.

## 2. Algorithm
1. Start.
2. Read the student's name.
3. Read marks for three subjects.
4. Add the three marks to calculate the total.
5. Divide the total by three to calculate the average.
6. If the average is at least 40, display Pass.
7. Otherwise, display Fail.
8. Display the student's name, total and average.
9. Stop.

## 3. Sample input
Name: Madhu; marks: 70, 80, 60

## 4. Actual output (sample run)
```text
Student Marks Calculator
Enter your name: Madhu
Enter marks for subject 1: 70
Enter marks for subject 2: 80
Enter marks for subject 3: 60
Student: Madhu
Total marks: 210
Average marks: 70.0
Result: Pass
```
