# Product Price Change Report

**Original program file:** `task.py10`

## 1. Aim
Calculate the percentage price change for products and identify the largest change.

## 2. Algorithm
1. Start.
2. Store product names and their prices.
3. Read the allowed percentage-change limit.
4. For each product, take its first and last prices.
5. Calculate percentage change from first price to last price.
6. Display the percentage change.
7. Compare the absolute change with the limit and warn if it is higher.
8. Track the product with the largest absolute change.
9. Display the largest change.
10. Stop.

## 3. Sample input
Price-change limit: 15%

## 4. Actual output (sample run)
```text
Product Price Change Report
Enter the price change limit percentage: 15
Rice changed by 20.0 %
Price change is above the limit.
Milk changed by 3.33 %
Sugar changed by 25.0 %
Price change is above the limit.
Largest change: Sugar - 25.0 %
```

## 5. Conclusion
This program demonstrates lists, loops, percentage calculations and comparisons.
