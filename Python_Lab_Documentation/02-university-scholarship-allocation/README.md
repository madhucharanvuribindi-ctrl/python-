# University Scholarship Allocation

**Original program file:** `task.py1`

## 1. Aim
Select eligible students for scholarships using marks, attendance and family income.

## 2. Algorithm
1. Start.
2. Store scholarship rules and student details.
3. Calculate each student's average marks.
4. Check that every subject mark is at least 50.
5. Check average, attendance and family-income conditions.
6. Add students who satisfy every condition to the eligible list.
7. Sort eligible students by average, attendance, income and name.
8. Award scholarships to the top three; waitlist the rest.
9. Display scholarship results.
10. Stop.
